# 차트 학습 구현

최종 화면 기준: 2026-10-07. 초기 12단원·퀴즈 설계를 대체한 현재 구현을 정리한다.

## 실제 차트 위에서 체험

트레이딩의 ‘그래프 종류’를 조작하면 현재 화면에서 꺾은선 → 캔들 → OHLC 바 → 영역 → 기준선 → 하이킨아시 → 렌코를 소개한다. 테스트 요구에 따라 `ALWAYS_SHOW_CHART_TUTORIAL=true`로 매번 진입한다. `/trading?chartTour=1`과 학습 탭에서도 재시작한다.

‘같은 가격, 일곱 가지 그림’의 목적·설명·주의사항을 `chartGuideContent.js`에서 공유한다. 같은 자체 제작 OHLC 예시 12개를 모든 유형에 사용하며 종료하면 원래 종목 데이터와 차트 설정을 복원한다. 계좌·주문 API를 호출하지 않는다.

캔들은 다른 유형과 같은 두 개의 설명 표시에 가두지 않는다. 실제 봉의 해당 부분에 테두리와 연결선을 그리고, 별도의 ‘눌러 보기’ 버튼 없이 차트나 설명 영역을 탭하면 다음 설명으로 이동한다. 마지막 캔들 설명 뒤에는 OHLC 바 소개로 이어진다. 이전·확대·닫기 버튼과 유형 선택은 탭 진행에서 제외하고, 차트에 초점이 있을 때 Enter/Space로도 진행한다.

| 예시 | 실제 그래프에서 설명할 부분 |
|---|---|
| 예시 2 | 시가 100·종가 118·고가 120·저가 98의 위치 |
| 예시 2 ↔ 3 | 몸통 길이 18과 2를 같은 가격 축에서 비교 |
| 예시 3 | 몸통이 짧아도 장중 105~130으로 크게 흔들릴 수 있음 |
| 예시 4 | 긴 윗꼬리: 몸통 위 118부터 고가 138까지 |
| 예시 5 | 긴 아랫꼬리: 저가 96부터 몸통 아래 115까지 |
| 예시 6 | 음봉: 119에 시작해 103에 마감 |
| 예시 7 | 도지: 시작·끝은 100으로 같아도 94~112의 범위가 있음 |
| 예시 8 | 양봉 95→98이지만 전일 종가 100보다 2% 낮음 |

캔들 선택 시 팝업을 자동으로 열지 않는다. 마지막 캔들 설명에서만 표시되는 ‘전체 구조 크게 보기’를 누르면 큰 자체 SVG로 네 가격·몸통과 꼬리 길이·캔들 모양을 비교한다. 이 그림은 한 페이지 학습 가이드에서도 사용한다. 몸통은 **시작과 끝의 차이**, 꼬리는 **몸통 밖까지 움직인 범위**로 설명하며 ‘짧은 몸통/꼬리=하루 종일 움직이지 않음’이라는 오해를 피한다.

다른 유형은 정보 표현의 차이에 맞춘 비교를 제공한다. 꺾은선과 캔들, OHLC 바와 캔들, 영역과 꺾은선, 기준선 유무, 원래 캔들과 하이킨아시, 시간 기준 차트와 렌코를 비교한다. 마지막에는 선형/로그 축, 돌파 유지/실패, 가격/거래량, 짧은/긴 이동평균 그림을 선택해서 볼 수 있다.

## 화면과 접근성

안내창은 실제 SVG 대상의 화면 좌표를 추적한다. ResizeObserver, 화면 크기와 스크롤 변화에 맞춰 재배치하며 데스크톱은 옆, 좁은 화면은 위쪽 공간을 사용한다. 외곽 차트의 세로 여백은 위아래 16px로 확보했다.

모든 튜토리얼의 배경 어둡게 처리는 제거했다. 학습 중에는 원자료 표 보기 버튼과 ‘학습용 가상 가격 · 실제 종목 시세가 아닙니다’ 문구를 표시하지 않는다. 일반 차트의 원자료 표는 유지한다. 예시 번호와 직접 만든 가격은 교육 자료이며 실제 종목 성과로 제시하지 않는다.

배경 요소는 체험 중 inert 처리하고 종료 시 이전 상태와 초점을 복원한다. Escape는 열린 그림 팝업부터 닫고, 팝업이 없으면 소개를 종료한다. 키보드 이동과 작은 화면의 안내 스크롤을 지원한다.

## 한 페이지 개념 가이드

`/learn/charts`는 작은 비교 그림과 짧은 해설을 나란히 보여준다. 퀴즈·완료율·단원 진행·학습 메모 저장 기능은 없다. 그래프 7종, 캔들 네 가격과 모양, 축·거래량·이동평균·돌파 비교를 담고, 조사 본문의 개념 자료 1~14장은 주제별 펼침으로 보존한다. 교육 설계·평가 제안 15~16장은 학습자 화면에서 제외했다. 원본은 [자료조사 폴더](./자료조사/)에 있다.

사용자가 제시한 [KB 캔들차트 설명](https://kbthink.com/stock/chart.html)은 짧은 해설과 그림을 연결하는 구성의 참고 자료다. 제3자의 문구나 이미지를 복제하지 않았다. 상품 추천·수익 보장·패턴 성공률 단정을 피하고 합성 가격·후행성·실패 사례도 설명한다.

## 검증

차트 자동 테스트는 7개다. 7종 렌더링과 합성 OHLC/렌코/이동평균 계산, 첫 조작과 반복 진입, 캔들 8개 설명 이동, 선택적 확대 그림, 크기 변경 추적, 계좌 API 미호출, 종료 시 원자료 복원, 퀴즈 부재를 검사한다. 브라우저에서도 실제 봉 강조와 옆 봉 이동, 자동 팝업 부재를 확인했다.

실제 초보 학습자를 대상으로 한 교육 효과는 아직 측정하지 않았다. 사용성 면담에서 OHLC 판독, 양봉과 전일 대비 상승 구분, 합성 가격 식별, 실패 가능성 설명을 관찰해야 한다. 수익률이나 화면 완료를 이해도 인증으로 사용하지 않는다.
