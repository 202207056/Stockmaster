## 3. 기획 배경 (발표자료 문제의식)

- 코스피 7000 돌파, 8000 시대를 앞둔 **역대급 불장** → 주식 관심도 급증
- 그러나 최근 2년간 **수익을 냈다는 응답은 46%** (뉴시스) → 강세장에서도 절반 이상이 손실
- 금융투자를 아예 하지 않는 21.8%, 그중 8.5%는 "원금 손실 가능성이 싫어서", "필요성을 못 느껴서"
- **경제에 대한 이해 없이 투자를 시도해 돈을 잃는 사람들**이 존재

→ **"주식 입문을 돕는 학습 플랫폼이 필요하다"** 는 것이 본 프로젝트의 출발점.

### 이 배경이 설계에 주는 함의 (중요)
본 프로젝트는 "모의투자 게임"이 아니라 **"학습 플랫폼"** 입니다.
따라서 아래 두 가지가 다른 모의투자 서비스와의 차별점이자 **평가 포인트**가 되어야 합니다.

1. **손실 발생 시 관련 개념 학습 시스템** — 실패를 학습으로 전환하는 루프
2. **페이지 내 도움말 아이콘** — 어려운 용어를 그 자리에서 즉시 해소

현재 DB 설계와 프론트엔드 어디에도 이 두 기능의 흔적이 없습니다. (→ `06_DB_설계.md`, `10_AI_및_학습시스템_설계.md` 참조)

## 4. 핵심 목표 (발표자료 원문)

- 초보 투자자가 가상의 자금을 통해 실제 돈을 잃지 않고 투자 경험을 학습
- 경제·주식 개념을 실전과 연결하여 이해
- AI를 활용해 사용자 투자 성향 분석 및 맞춤형 피드백 제공
- 초보자가 접근하기 쉬운 편리한 UI로 진입 장벽 완화
- 안전한 주식투자 개념과 위험자산의 위험성 교육

## 5. 기능 요구사항 (5대 도메인)

### D1. 사용자 및 계정
- 회원가입 및 로그인/로그아웃
- 사용자 프로필 설정
- 통합 자산 대시보드
- 개인 포트폴리오 관리

### D2. 모의투자 기능 (핵심)
- 매도/매수
- 그래프/차트
- 가격 조회
- 종목 목록/검색

### D3. 투자 성향 분석 (AI)
- AI 투자 코치
- AI 이슈 요약
- 설문을 통한 사용자 성향 파악

### D4. 적응형 학습 시스템 (핵심)
- 페이지 내 도움말 아이콘을 두어 어려운 정보를 즉각 습득
- 기본 투자 가이드
- 단계별 개념 학습 및 퀴즈
- **손실 발생 시 관련 개념 학습 시스템**

### D5. 커뮤니티
- 게시글 작성 및 수정
- 댓글, 좋아요, 팔로우
- 종목별 토론 게시판

### D6. 복잡한 UI 탈피 (전 도메인 공통 제약)
기존 HTS/MTS의 복잡한 인터페이스를 간략화하여 초보자 접근성 확보.
→ 기능 요구사항이라기보다 **모든 화면에 적용되는 설계 원칙**으로 취급.

### 🔑 API 사용 범위 (팀 확정 사항 · 2026-08-25)
> **한국투자증권 Open API는 "시세(Market Data) 조회" 용도로만 사용한다.**
> 모의투자 계좌, 주문·체결, 잔고, 사용자 계정은 **전부 자체 구현**한다.

이 결정은 아키텍처 전반에 영향을 주는 가장 중요한 제약입니다.

| 구분 | KIS API 사용 | 자체 구현 |
|---|---|---|
| 현재가·호가·차트·지수·종목마스터 | ✅ | |
| 회원가입/로그인/세션 | | ✅ |
| 모의 계좌·예수금·증거금 | | ✅ |
| 주문 접수·체결·정정·취소 | | ✅ (체결 엔진 자체 개발) |
| 잔고·포트폴리오·손익 계산 | | ✅ |
| 수수료·세금 계산 | | ✅ |

→ 따라서 **"모의 체결 엔진"이 본 프로젝트 백엔드의 심장**이며,
KIS의 모의투자 주문 API(`VTTC*` TR)는 사용하지 않습니다. 상세는 `09_모의체결엔진_설계.md`.
