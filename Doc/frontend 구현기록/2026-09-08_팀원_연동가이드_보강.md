# 팀원 연동 가이드 보강

- 대상: [팀원 API 연동 실행 가이드](../팀원_연동_실행가이드.md)
- 배포 백엔드 사용과 로컬 백엔드 실행을 분리하고, 코드 공유·환경 파일·실행 명령·계정 생성 절차를 상세화했다.
- 독립 개발 DB 생성, 기존 마이그레이션 적용, 종목 시드 입력 절차를 추가했다.
- 화면별 API와 통과 기준, Network 및 Swagger 비교 방법, 관심종목·차트 오류 전달 양식을 정리했다.
- 상단 지표 미구현, 주문 기본 비활성화, 관심종목 로컬 저장 등 현재 동작을 명시했다.
- 코드의 경로·설정·API 계약과 문서 명령을 대조하고 문서 링크를 확인했다. 신규 DB 설치나 인증 후 배포 API 호출을 수행한 것은 아니다.
- 프론트·백엔드 기능 및 디자인, 환경 파일은 변경하지 않았다. 커밋·push·배포도 수행하지 않았다.
