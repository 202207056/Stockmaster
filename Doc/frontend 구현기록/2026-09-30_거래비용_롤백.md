# 수수료·세금 적용 롤백

2026-09-30 사용자 요청: 수수료를 적용하기 이전으로 복원.

## 범위

- 백엔드 비용 적용 커밋 `df4f0ea`를 되돌림 커밋으로 취소했다. 기존 원격 뉴스 요약 개선 등 다른 변경은 유지한다.
- 매수·매도 현금 증감은 서버 체결가격 × 수량만 반영한다. 수수료·증권거래세·농어촌특별세를 차감하지 않는다.
- 비용 정책 API·정책 버전 요청·과세 종목 분류·비용/실현손익 저장·취득원가 필드·관련 마이그레이션 및 시드 변경을 제거했다.
- 프론트도 비용 정책 조회/구버전 판별을 제거했다. 주문 확인과 주문내역의 비용 표, 비용 포함 원가 계산을 제거하고 평균단가 × 수량 기준으로 되돌렸다.
- 사이트 조작형 튜토리얼 6개와 기존 예비 튜토리얼은 유지했다. 수수료 차감 단계와 적용된다고 표현한 설명을 제거하고 비용 제외 거래금액으로 맞췄다. 용어집의 일반적인 수수료·세금 개념은 유지한다.
- 50,000원에 10주 매수하면 현금 500,000원 감소, 그중 5주를 같은 가격에 매도하면 250,000원 증가한다. 초기 현금 1,000,000원 기준 최종 현금 750,000원 + 보유주식 250,000원으로 총자산은 유지된다.

## DB와 배포

운영 DB에 직접 접속하거나 마이그레이션·downgrade·잔고 수정을 실행하지 않았다. 이전에도 이 작업에서는 실제 DB 마이그레이션을 적용하지 않았다.

서버 담당자가 비용 마이그레이션을 아직 적용하지 않았다면 해당 마이그레이션을 실행할 필요가 없다. 이미 별도로 적용했다면 코드 롤백과 물리적 DB 롤백을 구분해야 한다. 추가 컬럼이 남아 있어도 이전 모델은 이를 사용하지 않지만, Alembic revision `c20260930_cost_policy`는 되돌린 코드에 존재하지 않으므로 향후 마이그레이션 전에 담당자가 DB revision과 스키마를 확인해야 한다. 버전만 임의로 stamp하거나 운영 데이터 컬럼을 바로 삭제하지 않는다. 이미 차감된 비용이 있다면 코드 롤백으로 환급되지는 않는다.

원격 push는 소스 반영이며 실제 서버의 배포 완료를 의미하지 않는다. 프론트와 백엔드의 롤백 버전을 함께 배포해야 한다.

## 검증

백엔드 기존 unittest 28개 통과. 프론트 린트·빌드와 자동 테스트 69개 통과. 프론트 주문 테스트는 정책 API 호출 없이 확인 창을 거쳐 주문이 완료되는지 검사한다. 연습 계좌 테스트는 비용 없이 전액 매수·일부 매도·잔고 부족·초과 매도 거절을 확인한다. 튜토리얼 DOM 테스트는 6개 과정과 계좌 데이터 격리를 검증한다.

이전 비용 적용 기록은 과거 구현 자료로 보존하며 현재 동작을 설명하는 문서로 사용하지 않는다.
