# 학습 배치 및 커리큘럼 재정립

## 요청과 판단

- 최신 요청에 따라 학습 첫 화면을 ‘투자 기초 과정’으로 변경했다. 이전의 ‘코스는 첫 화면이 아니다’라는 배치는 이번 요청으로 대체한다. 거래의 선행 필수 과정으로 강제하지 않는다.
- ‘보유 비중 비교하기’를 ‘투자 비중에 따른 손익 변화’로 변경하고 내 자산으로 이동했다. 실제 자산 데이터를 가상 계좌에 섞지 않는다. 같은 주가 변동이 비중에 따라 계좌에 다르게 반영된다는 학습 목적을 설명한다.
- 문장 퀴즈는 과정 목록 아래 접힌 보조 활동으로 유지한다. 별도 실습 탭과 오답 문제 피드를 없애 학습 중심이 분산되지 않도록 했다. 기존 퀴즈 기록은 삭제하지 않는다.
- 용어집은 상단 버튼으로 열고 ‘투자 기초 과정’ 버튼으로 돌아온다. 암기 활동은 없다.
- 독립 거래 복기 탭은 제거하고 가상 거래 연습을 매수 전 판단 점검 안에 배치했다. 현재 주문 예상 금액 → 가상 사례의 근거·체결·보유·매도·복기 → 현재 종목 판단 메모로 이어진다. 가상 사례가 선택한 종목의 예측처럼 보이지 않도록 설명하고 자동 복사를 하지 않는다.
- 매도 화면에는 현재 판단 기록을 유지하고 매수 사례는 표시하지 않는다. 주문 함수·폼·전송 계약은 수정하지 않았다. 가상 연습 기록은 기존 사용자 범위를 보존하고 종목 메모는 기존 사용자·계좌·종목 범위를 유지한다.
- 기존 home/practice/review URL은 기본 과정으로 표시한다. courses 및 lesson URL과 기존 진도 저장 키는 유지한다.

## 커리큘럼과 향후 설계

5개 영역·15개 수업을 A 주문 → B 손익 → C 위험 → D 정보 → E 판단 순서로 안내하고 과정 완료 후 다음 수업 링크를 추가했다. 상황 → 실습 → 확인 문제 → 적용의 틀을 명시했다. 완료는 시도 기록이며 숙련 판정이 아니다.

손실/이익 발생 시 관련 개념 학습과 단계별 진단·전이 퀴즈는 향후 도입으로 문서화했다. 지금 내 자산에 추가한 것은 수동 수업 링크이다. 불완전한 시세와 손익을 사용해 자동 개인화가 된 것처럼 표시하지 않는다.

14번 MD/HTML 및 15번 아이디어를 최신 구조로 재정리했다. 각 기능의 발생 맥락·오해·행동·확인 기준을 명시했다. 학습 효과가 이미 검증되었다고 주장하지 않고 새 사례의 첫 응답과 설명으로 검증하도록 정했다. 용어 암기·수익률 보상·근거 없는 성향 단정은 제외했다.

## 백엔드 후속 작업

백엔드 파일은 변경하지 않았다. 미래 자동 학습에는 다음이 필요하다.

1. 사용자·계좌·종목 소유권 검증 및 손익 사건 ID. 평가/실현 상태, 원가 배분, 비용, 잔여 수량, 가격 기준시각을 제공한다.
2. 추천 근거 코드와 콘텐츠 버전. 데이터 누락·미체결·시각 불일치 시 사건을 생성하지 않는다.
3. 사건별 표시/접기/완료/다시 보기 상태를 저장하여 재조회 때 중복 노출을 방지한다.
4. 단계별 선행 진단·최초 응답·재시도·새 사례 전이 응답을 구분해서 저장한다. 기존 완료 여부를 숙련 점수로 변환하지 않는다.
5. 주문과 판단 기록의 시점 연결은 서버 계약으로 보장한다. 현재 메모를 과거 체결 당시의 계획으로 소급하지 않는다.

세부 선정 규칙과 카드 구조는 [14번 설계](../자료/14_학습콘텐츠_및_기능설계.md)의 5~7절을 따른다. 기존 [백엔드 요청사항](./2026-09-15_학습기능_백엔드_요청사항.md)의 저장·주문 분리 계약도 유지한다.

## 검증

- 기존 스타일 토큰과 공통 레이아웃 유지. 브라우저에서 과정 우선 표시·접힌 보조 퀴즈·용어집 버튼과 기존 카드 디자인을 확인했다.
- 테스트: 학습 첫 화면 우선순위를 갱신하고 내 자산 배치·매수에만 가상 사례 노출·주문 submit 버튼 부재를 검증한다.
- ESLint 및 프로덕션 빌드 통과. 실제 주문·설문 제출·백엔드 데이터 변경은 하지 않았다.

## 후속 요청 반영: 좌측 학습 메뉴

2026-09-16 최신 배치: 내 자산은 총자산 → 내 투자 → 보유종목 → 손실/이익 발생 시 관련 개념 학습(현재 미구현) 순서다. 비중 비교·수동 학습 링크·보유 중 학습 패널은 내 자산에서 제거한다. 학습은 좌측 세로 메뉴(기본 투자 가이드 / 투자 기초 과정 / 투자 비중에 따른 손익 변화 / 내 주식은 왜 올랐을까/내렸을까?)와 우측 콘텐츠로 구성한다. 기본 진입은 이전 요청대로 투자 기초 과정이며, 좁은 화면에서는 세로 메뉴를 본문 위에 배치한다. 용어집 버튼과 과정 아래 보조 문장 퀴즈는 유지한다. 가격 변화 메뉴는 정보 확인 가이드와 D1·D2 수업 연결이며 개인 보유 종목 자동 분석은 미구현이다.

뒤의 요청을 우선하여 비중 비교를 내 자산 아래에 유지하는 대신 학습으로 옮겼다. 내 자산의 보유종목은 모든 학습 안내보다 먼저 표시한다. 보유 중 학습 패널의 화면 연결만 제거했고 저장된 메모와 트레이딩 판단 기록은 유지한다. 기본 가이드는 계좌·주문·손익·판단의 기존 수업 진입점을 제공한다. 새 API나 가격 원인 추론은 추가하지 않았다. 기존 공통 헤더·색상·카드 스타일과 백엔드는 변경하지 않았다.
