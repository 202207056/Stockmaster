# 2026-09-29 자산 조회 안정화

## 확인한 원인
- 자산 페이지와 미니 팝업이 같은 계좌의 포트폴리오와 종목별 현재가를 각각 요청했다.
- 팝업의 window focus 이벤트가 진행 중인 조회도 취소하고 재시작했다.
- useRemote는 새로고침마다 기존 데이터를 지워 총자산과 평가금액이 사라졌다.
- 종목 시세 실패는 quote: null로만 처리되어 합계가 사라진 이유를 알 수 없었다.
- 로컬 백엔드의 현재가 구현은 키 미설정 시 0과 message를 반환한다. 이를 포함한 유효하지 않은 가격은 합계 계산에 사용할 수 없다. 실제 운영 장애가 키 설정 때문인지는 확인하지 않았다.

## 변경
- 동일 세션·계좌의 진행 중인 자산 요청 공유. 모든 구독자가 취소한 경우에만 원본 요청 취소. 완료 데이터 캐시는 없음.
- 조회 중 포커스 재시작 방지, 정상 조회 후 30초 이내 포커스 재조회 생략.
- 자산 화면에 한해 갱신 중/실패 시 이전 데이터를 유지하고 이전 조회 금액임을 안내. 계좌나 사용자가 바뀌면 재사용하지 않음.
- 일시적 네트워크/5xx/429 오류와 유효하지 않은 현재가는 1초 후 1회 재시도. 일반 4xx는 재시도하지 않음.
- 실패 종목별 사유와 재조회 안내 표시. 누락된 시세를 0원이나 매입가로 대체하지 않음.

## 검증 및 한계
- 린트, 빌드, 테스트 52개 통과. 기존 번들 크기 경고 유지.
- 추가 검증: 요청 공유·계좌/세션 분리·취소·실패 후 재조회·일시 시세 오류 복구·0원 응답 및 영구 오류 처리.
- 실제 로그인 계좌 응답 및 배포 서버 로그는 확인하지 못했으므로 외부 시세 서비스의 지속적인 장애까지 해결되었다고 단정하지 않는다. 백엔드 변경/배포는 하지 않았다.
