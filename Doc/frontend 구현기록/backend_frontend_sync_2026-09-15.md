# 2026-09-15 백엔드 변경 반영

추가: 주요 시세의 `intraday.points`를 연결해 당일 10분 간격 지수 요약 차트로 변경했다. 상승/하락 배경색은 전일 대비 등락률 기준으로 유지한다. 전일 종가와 현재를 잇던 직선 및 하단 문구는 제거했다. 백엔드 `get_market_indices`의 새 필드가 함께 배포되어야 하며, 구버전 응답이나 빈 데이터는 차트 준비 중으로 표시한다. 프론트 테스트는 20개 통과했다.

기준: `gp-mock-inv/Doc/backend 구현기록/2026-09-11_시세_주문_AI코칭.md`와 현재 백엔드 코드.

| 백엔드 계약 | 프론트 반영 |
|---|---|
| 공개 종목·뉴스·종목순위 | 비로그인 요청 및 화면 표시 허용 |
| `GET /api/market/indices` | 홈에 값·등락률 표시. null은 준비 중, 요청 실패는 재시도 제공 |
| `GET /api/ai/coach?symbol=...` | 트레이딩에서 선택한 종목의 코칭 표시. 로그인 필요. 첫 번째 계좌 기준 및 3분 캐시 안내 |
| `POST /api/ai/survey` | 저장·분석을 한 번만 요청. 서버 성향·요약·조언·학습 주제 표시. 로컬 성향으로 덮어쓰던 후속 PUT 제거 |
| `POST /api/trading/orders` | 기존 요청 필드 및 응답 체결가 표시 유지. 서버 현재가로 체결되는 점 안내 |
| 계좌·주문·커뮤니티·설문 | 백엔드 인증 조건 유지 |

주문은 기존 `VITE_ENABLE_ORDER_SUBMISSION=false` 설정을 유지한다. 대상 배포의 모의 주문을 검증한 뒤 true로 설정하고 프론트를 다시 빌드해야 한다. 이번 작업에서 주문을 전송하거나 배포하지 않았다.

## 자동 반영 범위

이미 연결된 API가 같은 형식으로 다른 데이터를 반환하면 다음 조회에 반영된다. 새 API, 응답 구조, 인증 조건, 새로운 화면은 프론트 수정과 배포가 필요하다. 이 프로젝트에는 백엔드 변경으로 프론트 구현을 자동 생성하는 기능이 없다.

후속 변경 시 백엔드 구현기록 및 API 계약과 `frontend/src/api/data.js`, 호출 화면, `frontend/tests/integration.test.mjs`를 함께 갱신한다. 테스트는 로컬 응답 대역으로 검사하며 배포 API 변경을 자동 추적하지 않는다.

## 검증

- 공개 조회, 지수 null 표시, 코칭 종목·인증 헤더, 설문 서버 결과 표시 검증.
- 실제 배포 서버의 KIS·Gemini 응답 및 주문 체결은 미검증.
