## 현재 구현 상태

2026-10-06: 수수료 0.015%·매도 거래세 0.18%와 시장가/지정가 API 변경을 다시 반영했다. 예약·조건 주문은 별도 서버 감시 기능으로 추가했으며, 기존 지정가 대기의 자동 체결과는 구분한다. 신규 기능의 분석·설계·검증 및 배포 순서는 [예약·조건 주문 문서](./2026-10-06_예약_조건주문_분석_및_설계.md)를 우선 확인한다. 아래 내용은 과거 기록이다.

2026-09-30 최종 변경: 사용자 요청으로 수수료·세금 적용을 롤백했다. 거래대금만 현금에 반영하며 사이트 조작 튜토리얼은 유지한다. 아래 비용 적용 설명은 이전 기록이다. [롤백 기록](<./frontend 구현기록/2026-09-30_거래비용_롤백.md>)을 우선 확인한다.

2026-09-30 변경: 실제 트레이딩·내 자산 화면에서 진행하는 6개 조작 튜토리얼과 일반주식 모의거래의 수수료·세금 처리를 구현했다. 기존 튜토리얼은 예비 연습으로 보존했다. 미수·선물 등 현재 사이트에 거래 기능이 없는 심화 튜토리얼은 미구현이다. 백엔드 코드와 DB 마이그레이션도 추가했으나 운영 반영은 실행하지 않았다. 설정·근거·검증·반영 순서는 [거래 튜토리얼 및 비용 구현기록](<./frontend 구현기록/2026-09-30_거래튜토리얼_확장_및_거래비용_적용.md>)에서 확인한다. 아래 내용은 이전 시점의 기록이다.

2026-09-15 학습 업데이트: `/learn`에 비교 실습·문맥 퀴즈·선택형 코스·가상 거래 복기를 추가했다. Trading/Assets에는 접이식 기기 메모를 연결했다. 학습 신규 API는 호출하지 않으며 백엔드는 변경하지 않았다. 최신 검증은 자동 테스트 30개와 브라우저 화면 확인이며, 아래 연동 상태 표는 9월 9일 기준 기록이다.

### 로컬 참고자료

이 작업 폴더의 `자료/`에는 기존 `00`~`13` 문서와 중간발표 PDF가 있습니다. 프로젝트 개요, 아키텍처, API·DB·KIS 설계, 과제 평가 등을 참고할 수 있습니다.

**`Doc/자료/`는 현재 `.gitignore`에 포함되어 있어 clone·pull로 전달되지 않습니다.** 따라서 이 README의 공유 문서 목록에는 해당 파일의 링크를 넣지 않습니다. 자료가 필요한 팀원은 별도 전달 여부를 확인합니다. 기존 문서는 작성 시점의 설계·계획을 포함하므로 현재 구현 상태로 단정하지 않습니다.

이전에 안내했던 `Doc/구현기록/`와 `Doc/_archive/`는 현재 작업 폴더에 없습니다. 새 프론트 기록은 `Doc/frontend 구현기록/`에서 관리합니다.

## 프로젝트의 기본 방향

- KIS는 외부 시세·차트·순위 조회에 사용하고, 회원·모의 계좌·주문·자산은 자체 백엔드에서 관리합니다.
- 모의투자와 경제학습을 연결하는 서비스이며, 학습·AI 관련 계획과 실제 구현 완료 여부는 구분해 기록합니다.
- 프론트에서 KIS 키나 DB 비밀번호를 직접 사용하지 않습니다. 프론트는 설정된 백엔드 API에 요청합니다.

## 문서 관리 기준

- 실행 명령·환경 설정·오류 진단 절차가 바뀌면 연동 가이드를 갱신합니다.
- 프론트 변경은 `frontend 구현기록/`에 변경 이유, 검증 결과, 남은 제한을 간단히 남깁니다.
- API 변경은 프론트·백엔드 담당자가 경로와 요청·응답 형식을 맞추고 배포 반영 여부도 확인합니다.
- 검증한 사실과 미검증 항목을 구분하고, 근거 없는 진척률이나 완료 표현을 사용하지 않습니다.
- 파일 이동·삭제 시 이 목차와 링크를 함께 수정합니다. 공유 문서는 Git 추적 여부까지 확인합니다.
- 비밀번호·토큰·API 키 등 비밀값은 문서나 Git에 넣지 않습니다.
