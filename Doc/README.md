## 30초 요약

한국투자증권 Open API로 **실제 시세**만 받아오고, 계좌·주문·체결·자산은 **전부 자체 구현**한
모의투자 플랫폼입니다. AI가 투자 성향을 분석하고, **손실이 나면 관련 개념 학습으로 연결**하는 것이
다른 모의투자 서비스와 다른 점입니다.

- **전체 진척 약 45~50%** — 백엔드 27개 엔드포인트가 배포되어 동작하고, React 프론트는
  기반 작업과 UI 시안이 끝났습니다. **둘이 아직 연결되지 않았습니다.**
- **지금 할 일** — ① 백엔드 거래 결함 4건 수정 → ② React ↔ 백엔드 연동 → ③ 학습·AI 채우기

## 이 프로젝트의 핵심 설계 결정 3가지

### 1. KIS API는 시세 전용

```text
KIS Open API  →  현재가 · 호가 · 봉 · 지수 · 랭킹        (읽기 전용)
자체 구현      →  회원 · 계좌 · 주문 · 체결 · 잔고 · 손익  (전부)
```

KIS의 모의투자 **주문 API는 사용하지 않습니다.** 사용자마다 증권 계좌가 필요해 불가능하고,
체결 이벤트를 가로챌 수 없어 "손실 → 학습" 연결이 불가능하기 때문입니다.

순위분석 TR이 실전 계좌에서만 제공되므로 **실전 앱키**를 쓰되, 해당 계좌는
**예수금 0원 · 주문 TR 코드 차단** 상태로 운용합니다. → `08_KIS_실전계좌_안전운용.md`

### 2. 체결 엔진이 백엔드의 심장

시세를 기준으로 지정가/시장가 체결을 판정하고, **하나의 트랜잭션 안에서** 주문·체결·
포트폴리오·예수금·원장을 갱신합니다. `locked_cash`(예약금 잠금)를 빼먹으면 예수금보다 많이
사는 버그가 반드시 발생합니다. → `09_모의체결엔진_설계.md`

### 3. 차별화는 "손실 → 학습"과 "도움말 아이콘"

다른 모의투자 서비스에 없고, 발표자료가 약속했으며, 구현 난이도 대비 임팩트가 가장 큽니다.
도움말 아이콘은 **프론트에 이미 24개소 구현**되어 있고, 손실→학습 트리거는 아직 없습니다.
→ `10_AI_및_학습시스템_설계.md`
