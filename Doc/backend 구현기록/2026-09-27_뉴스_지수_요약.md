# 2026-09-27 · 뉴스·지수 미니차트·뉴스 요약

백엔드 저장소 `gp-mock-inv`만 변경했다. 팀 프론트 코드와 팀 저장소 `Stockmaster`는 변경하지 않았다.

배포 반영은 개인 GitHub `main` 푸시 후 Render 빌드가 끝난 뒤에 확인할 수 있다. 명세: `https://gp-mock-inv.onrender.com/docs`

이전 기록 [2026-09-11 · 시세·주문 검증·AI 코칭](./2026-09-11_시세_주문_AI코칭.md)에서 하지 않는다고 적었던 지수 미니차트, 나스닥·S&P·금·달러, 뉴스 요약을 이 작업에서 다뤘다.

## 변경 요약

| 영역 | 구현한 내용 | 개인 `main` 커밋 |
|---|---|---|
| 지수 미니차트 | 기존 `GET /api/market/indices`의 코스피·코스닥에 `intraday` 추가. 실전 KIS 지수 분봉을 10분 간격 `points`로 묶음. 포인트가 2개 미만이면 `intraday`를 빼서 프론트가 "차트 준비 중"을 유지 | `16ff369` |
| 시장 뉴스 | `GET /api/news/market`. 예전 네이버 금융 목록에는 기사가 없어 `[]`였다. 네이버 뉴스 증권면(`news.naver.com/breakingnews/section/101/258`)에서 제목·링크·요약·언론사·시간을 읽음 | `904b679` |
| 종목 뉴스 | `GET /api/news/{symbol_code}`. 예전 `finance.naver.com/item/news_news.naver`는 404라 `[]`였다. `m.stock.naver.com/api/news/stock/{code}` JSON으로 변경 | `3f248f3` |
| 뉴스 요약 | 새 경로를 만들지 않음. `GET /api/ai/news-summary/{symbol_code}`가 종목 뉴스 5건을 Gemini에 보내 제목·요약·태그를 반환. 기사 제목이 없으면 Gemini를 호출하지 않음. 같은 종목 3분 캐시 | `2ebb3d5` |
| 해외·원자재 카드 | 같은 지수 API의 나스닥·S&P 500·금·달러를 네이버 시세 JSON으로 채움. 금은 국내 금(원/g). 이 네 카드에는 `intraday`가 없음 | `c88ce52` |

코스피·코스닥 현재지수는 계속 실전 KIS `inquire-index-price`다. 종목 현재가·일봉 차트는 모의투자 키다. 뉴스 요약·설문·코치는 같은 Render `GEMINI_API_KEY`와 `gemini-3.6-flash`를 쓴다. 추천 `GET /api/ai/recommend`와 패턴 `GET /api/ai/pattern`은 여전히 별도 AI 서버라, 서버가 없으면 503이다.

## 프론트가 부르면 되는 계약

홈은 이미 `GET /api/market/indices`와 `GET /api/news/market`을 부른다. 종목 뉴스와 뉴스 요약은 백엔드에 있으나, 2026-09-27 팀 `main`의 `frontend/src/api/data.js`에는 호출이 없다.

```http
GET /api/market/indices
```

로그인 없이 호출할 수 있다. 코스피·코스닥만 `intraday`가 있다. `points`의 `time`은 `HHMMSS`이고 `090000`~`153000`이다.

```json
[
  {
    "code": "kospi",
    "name": "코스피",
    "value": 7080.92,
    "change_rate": 0.9,
    "intraday": {
      "date": "20260923",
      "points": [
        { "time": "090000", "value": 7126.42 },
        { "time": "153000", "value": 7078.93 }
      ]
    }
  },
  { "code": "nasdaq", "name": "나스닥", "value": 27068.72, "change_rate": 0.48 },
  { "code": "sp500", "name": "S&P 500", "value": 7743.41, "change_rate": 0.51 },
  { "code": "gold", "name": "금", "value": 189500, "change_rate": 0.2 },
  { "code": "usd", "name": "달러", "value": 1359, "change_rate": 0.26 }
]
```

금 `189500`은 국내 금 원/g이다. 국제 금(달러/온스)이 아니다. 달러는 원/달러다. 나스닥은 `.IXIC`, S&P 500은 `.INX`다. 조회가 실패하면 그 카드만 `value: null`이고, 프론트는 "준비 중"을 유지하면 된다. 네 카드는 `intraday`가 없으므로 미니차트는 "차트 준비 중"이다.

```http
GET /api/news/market?limit=8
GET /api/news/005930?limit=3
```

둘 다 로그인 없이 호출할 수 있다. 기사 본문 전체는 주지 않는다. 네이버 페이지는 사이트 안에 iframe으로 열 수 없다.

```json
[
  {
    "title": "기사 제목",
    "url": "https://n.news.naver.com/mnews/article/...",
    "summary": "본문 앞부분",
    "source": "언론사",
    "date": "2026.09.27 13:19"
  }
]
```

```http
GET /api/ai/news-summary/005930
```

로그인(Bearer) 필요. 매수·매도 지시가 아니라 기사에 있는 언급 이유만 정리한다.

```json
{
  "symbol_code": "005930",
  "name": "삼성전자",
  "headline": "반도체 호황 기대 및 배당 호재와 함께 해외 박람회서 AI 기술 선보여",
  "change_rate": 3.62,
  "summary": ["요약 문장 1", "요약 문장 2", "요약 문장 3"],
  "tags": ["태그1", "태그2", "태그3"],
  "disclaimer": "본 정보는 모의투자 연습용으로 제공되며, 어떠한 투자 권유나 종목 추천이 아닙니다."
}
```

## 프론트 문서 대비

| 팀 문서·화면 | 이 작업에서의 처리 |
|---|---|
| `backend_frontend_sync_2026-09-15`의 지수 `intraday.points` | 코스피·코스닥만 채움. 포인트 2개 미만·장 마감으로 점이 없으면 필드를 빼 프론트 "차트 준비 중" 유지 |
| 홈 시장 뉴스 `fetchNews` → `/news/market?limit=8` | 빈 배열이던 원인을 고쳐 제목·요약·출처·시간·외부 링크가 내려감 |
| 종목별 뉴스, "왜 움직였는지" 요약 | 백엔드만 준비. 화면 연결은 프론트 담당 |
| 옆·아래 보유·인기 종목 등락 띠 | 새 API 없음. 거래대금 순위와 포트폴리오·현재가로 프론트가 구성 가능 |
| 학습 진도·판단 기록 API (`2026-09-15_학습기능_백엔드_요청사항`) | 하지 않음. 문서는 팀 합의 전이라 지금 호출하지 않는다고 적혀 있음 |
| 주문 버튼 `VITE_ENABLE_ORDER_SUBMISSION` | 백엔드에서 켜지 않음. 기존 주문 조회는 동작 |

## 검증

2026-09-27에 `https://gp-mock-inv.onrender.com`을 조회했다. 비밀번호는 문서에 적지 않는다.

| 확인 | 결과 |
|---|---|
| `GET /api/market/indices` 코스피·코스닥 | 200. 값·등락률과 `intraday` 각 40포인트. 날짜 `20260923`(일요일 점검이라 마지막 거래일) |
| `GET /api/news/market?limit=1` | 200. 제목, `n.news.naver.com` 링크, 요약 있음. 배포 직후 한 번은 `[]`였고, 새로고침 후 기사가 보임 |
| `GET /api/news/005930?limit=1` | 200. 삼성전자 기사 있음 |
| 종목 검색·상세·현재가, 거래량·거래대금·등락률 순위 | 200 |
| `GET /api/stocks/005930/chart?range=D` | 200 |
| `GET /api/stocks/005930/chart?period=D` | 첫 호출 500, 바로 다시 호출하면 200. 모의투자 시세 시간 초과가 그대로 500이 되는 기존 경로 |
| 로그인 후 내 정보, 계좌, 보유, 주문 내역, 설문, 투자성향, 랭킹, 커뮤니티 글 | 200 |
| `GET /api/ai/coach?symbol=005930` | 200. 현재가와 보유 수익률이 들어간 조언 |
| `GET /api/ai/news-summary/005930` | 200. 제목, 요약 3줄, 태그 3개 |
| `GET /api/ai/recommend`, `GET /api/ai/pattern` | 503. AI팀 서버 연결 실패 |
| 나스닥·S&P·금·달러 | 코드는 `c88ce52`로 `origin/main`에 푸시함. 문서 작성 직전 조회는 아직 `value: null`. Render 배포가 끝나기 전이라 숫자 반영은 재확인이 필요 |

개인 저장소 `main`에만 푸시했다. 팀 `backend` 브랜치 마지막은 2026-09-14 `437783b`라 이 작업이 없다. 팀 `main` 프론트는 2026-09-23 `727172b`(학습 튜토리얼·관심종목)까지다.

## 하지 않은 것

- 나스닥·S&P·금·달러 미니차트
- 종목 뉴스·뉴스 요약을 프론트 화면에 연결
- 보유·인기 종목 등락 띠
- 일봉 `period=D` 시간 초과를 500 대신 처리
- 학습 진도·판단 메모·주문 연결 API
- `recommend`, `pattern`을 Gemini로 교체
- 팀 저장소 푸시

## 다음 확인 순서

1. Render가 `c88ce52`를 배포했는지 보고 `GET /api/market/indices`에서 나스닥·S&P·금·달러 `value`가 숫자인지 확인한다.
2. 프론트는 시장 뉴스와 코스피·코스닥 미니차트를 새로고침으로 확인하면 된다. 새 주소는 없다.
3. 종목 뉴스와 뉴스 요약을 화면에 넣을 때는 `GET /api/news/{코드}`, `GET /api/ai/news-summary/{코드}`를 쓰면 된다. 뉴스 요약은 로그인이 필요하다.
