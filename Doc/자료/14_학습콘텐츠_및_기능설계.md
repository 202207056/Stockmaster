# Stockmaster 학습 기능 설계 — 투자 기초 과정과 거래 맥락

> 2026-09-16 최신 배치: 내 자산은 총자산 → 내 투자 → 보유종목 → 손실/이익 발생 시 관련 개념 학습(현재 미구현) 순서다. 비중 비교·수동 학습 링크·보유 중 학습 패널은 내 자산에서 제거한다. 학습은 좌측 세로 메뉴(기본 투자 가이드 / 투자 기초 과정 / 투자 비중에 따른 손익 변화 / 내 주식은 왜 올랐을까/내렸을까?)와 우측 콘텐츠로 구성한다. 기본 진입은 이전 요청대로 투자 기초 과정이며, 좁은 화면에서는 세로 메뉴를 본문 위에 배치한다. 용어집 버튼과 과정 아래 보조 문장 퀴즈는 유지한다. 가격 변화 메뉴는 정보 확인 가이드와 D1·D2 수업 연결이며 개인 보유 종목 자동 분석은 미구현이다.

기준: 2026-09-16. 이전의 추천 활동·거래 복기 중심 배치를 이 문서로 대체한다. 백엔드 변경 없이 구현한 화면과 향후 기능을 구분한다.

## 1. 비전과 도입 기준
사용자가 숫자와 정보를 해석하고, 거래 전에 확인할 근거를 남기며, 결과와 판단 과정을 구분할 수 있게 한다. 학습 탭의 첫 화면은 체계적인 투자 기초 과정이다. 거래는 과정 이수 없이 이용할 수 있다.
모든 기능은 발생 상황 → 해결할 오해 → 사용자 행동 → 관찰 가능한 확인 기준을 갖춘다. 아래 근거는 기능을 채택한 설계 논리이며 학습 효과가 실증되었다는 주장이 아니다. 출시 후 새 사례의 첫 응답과 설명을 통해 효과를 검증한다. 단순 체류 시간·수익률·거래 횟수는 성취 지표로 쓰지 않는다.

## 3. 커리큘럼
권장 순서는 A → B → C → D → E이다. 건너뛰기를 막지 않는다. 영역별 목표가 다르므로 수업마다 적용 상황을 명시한다.
| 단계 | 수업 | 수행 목표 | 연결 위치 |
| --- | --- | --- | --- |
| A 주문과 계좌 | A1 현금과 총자산 / A2 주문 대기 / A3 표시가와 체결가 | 주문 전후 자산 합계와 미체결 상태를 구분 | 매수 화면 |
| B 손익과 보유 | B1 평가손익 / B2 손실 회복률 / B3 평균단가 | 금액·수익률의 기준과 추가 매수의 노출 증가를 설명 | 내 자산 |
| C 금액과 위험 | C1 투자 비중 / C2 일부 매도 / C3 분산의 한계 | 계좌 전체 영향과 남은 보유분을 계산 | 내 자산·매도 |
| D 뉴스와 정보 | D1 뉴스와 가격 / D2 실적 해석 / D3 지표 비교 | 사실·해석·추측과 추가 확인할 자료를 구분 | 매수 근거 |
| E 계획과 복기 | E1 매수 근거 / E2 매도 이유 / E3 결과와 판단 | 당시 정보와 사후 정보를 분리해 다음 확인 사항을 작성 | 매수·보유·체결 |

공통 수업 틀: 상황과 자료 → 직접 계산·판단 → 확인 문제 2개와 해설 → 거래에 적용할 행동. 현재 완료 표시는 두 문제를 시도한 과정 이수 표시이며 숙련 판정이 아니다. 완료 후 다음 수업으로 이동한다.
향후 ‘단계별 개념 학습 및 퀴즈’는 이 틀을 확장한다. 선행 개념 진단 1문항 → 설명 → 수치/사실 비교 → 확인 2문항 → 숫자·문맥을 바꾼 전이 문제 1문항 → 오개념별 보충 설명으로 구성한다. 오답일 때 무작정 다음 단계를 잠그기보다 부족한 개념을 안내한다. 숙련 판정은 검토된 신규 전이 문제와 설명 평가 기준을 확보한 뒤 도입한다.

## 4. 매수 전 판단 점검의 구체적 흐름
1. 종목·수량 입력 후 조회 가격 기준 예상 금액과 잔여 현금을 확인한다. 비용 제외이며 체결 결과와 다를 수 있다.
2. 필요한 사용자는 ‘가상 사례로 매수 이후까지 확인하기’를 연다. 고정된 X기업 사례를 현재 선택 종목의 전망으로 표현하지 않는다.
3. 가상 매수 근거·불확실성과 재검토 조건을 기록한다. 미래 가격을 먼저 보여주지 않고 체결 → 하락 → 일부 매도 → 복기를 차례로 연다.
4. 최초 근거와 당시 계좌, 변경 판단, 실현·평가손익을 함께 비교한다. 수익·손실 자체를 정답으로 채점하지 않는다.
5. 같은 매수 패널의 현재 종목 판단 메모에 확인 사항을 명시적으로 저장한다. 가상 사례의 문장을 실제 매수 근거로 자동 복사하지 않는다.
6. 주문은 기존 주문 버튼에서 실행한다. 학습 저장은 주문 전송과 분리된다. 기존 체결 내역에서 사후 복기를 열 수 있지만 현재 메모를 주문 시점의 기록이라고 단정하지 않는다.

학습 탭의 독립 ‘거래 복기’ 메뉴와 대형 가상 거래 카드는 제거한다. 가상 연습은 매수 패널에서 접근하며 기존 사용자별 연습 기록을 보존한다. 종목 판단 기록은 사용자·계좌·종목별로 분리한다.

## 5. 향후 손실/이익 발생 시 관련 개념 학습 — 내 자산
현재 자동 손익 사건 탐지·개인화 추천은 미구현이다. 현재 내 자산에는 미구현 안내만 표시한다. 구현 위치는 내 자산의 해당 종목 손익 또는 체결 결과 아래이다. 강제 팝업과 수익률 순위는 넣지 않는다.
| 사건과 필요 자료 | 보여줄 내용·선정 이유 | 연결 학습·확인 문제 |
| --- | --- | --- |
| 보유 종목의 평가손익이 음수, 현재가·평균단가·수량 유효 | 아직 매도하지 않은 평가손실이라는 사실과 산식 | B1 → 가격을 바꿨을 때 평가손익 계산 |
| 평가손실에서 회복 조건을 살펴볼 때, 취득 기준 금액 유효 | 하락률과 회복에 필요한 상승률의 분모 차이 | B2 → 다른 하락률의 회복률 계산 |
| 평가손익이 양수, 미매도 상태 확인 | 평가이익과 확정된 이익을 구분 | B1 → 같은 보유분의 평가·실현 상태 구분 |
| 일부 매도 체결, 원가 배분·비용·잔여 수량 확정 | 판 부분과 남은 부분의 손익을 분리 | C2 → 잔여 수량과 실현·평가손익 구분 |
| 계좌 손익에서 특정 보유분의 기여를 비교, 동일 시점 평가액 확보 | 종목 수익률과 계좌 영향의 차이 | C1 → 가상 비중 비교와 계좌 변화 예측 |

카드 틀: ‘관측된 사실(시각·기준 포함)’ → ‘이 설명을 보여주는 이유’ → ‘개념 한 가지’ → ‘다른 숫자의 확인 문제’ → ‘해설 및 관련 과정’. 손익 부호만으로 잘못된 판단·투자성향·손절 필요성을 추론하지 않는다.
예: 평가손실 -30,000원 → ‘아직 보유 중인 수량의 현재 평가액과 매입금액 차이입니다’ → 가격이 달라진 별도 사례에서 평가손익을 계산. 이익 사례도 같은 원리로 제공하며 매도를 유도하지 않는다.
표시 규칙: 수동 새로고침마다 같은 학습을 반복 노출하지 않는다. 사용자·계좌·사건·콘텐츠 버전으로 중복을 방지하고 접기/다시 보기를 제공한다. 미체결·가격 누락·기준시각 불일치 시 사건을 만들지 않는다. 서로 다른 계좌의 손익을 합쳐 개인화하지 않는다.

## 6. 제외 및 검증 기준
제외: 용어 암기/카드/연속 출석 보상, 근거 없는 AI 성향 판단, 수익률 기반 숙련 점수, 맥락 없는 퀴즈 피드, 손익만 보고 거래를 지시하는 추천. 퀴즈·메모도 설명할 오해나 적용 행동을 지정하지 못하면 추가하지 않는다.
검증: 새 수치에서 손익을 계산할 수 있는지, 새로운 기사에서 사실과 추측을 구분하는지, 최초 근거와 추가 정보를 구분해 쓰는지 관찰한다. 기존 30문항 답을 외운 정답률과 새 문맥의 첫 응답을 분리한다. 효과가 확인되지 않는 활동은 확장하지 않고 문항·설명을 수정하거나 제거한다.

## 7. 구현 범위와 백엔드 의존성
이번 변경은 화면 배치·이름·진입 경로와 커리큘럼 안내를 정리한다. 기존 디자인 토큰·헤더·주문 처리는 유지한다. 학습·메모는 브라우저 로컬 저장이다.
향후 서버 작업: 손익 사건 ID/기준시각/원가와 비용/스냅샷, 계좌 소유권 검증, 분석 근거 코드, 사용자별 숨김/완료/재노출 상태, 콘텐츠 버전 및 전이 문제 첫 응답 기록. 주문 성공과 학습 저장 성공을 별도로 처리한다. 자료가 부족하면 자동 추천을 만들지 않는다.
