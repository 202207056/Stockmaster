# 학습 아이디어 우선순위 — 2026-09-16

> 2026-09-16 최신 배치: 내 자산은 총자산 → 내 투자 → 보유종목 → 손실/이익 발생 시 관련 개념 학습(현재 미구현) 순서다. 비중 비교·수동 학습 링크·보유 중 학습 패널은 내 자산에서 제거한다. 학습은 좌측 세로 메뉴(기본 투자 가이드 / 투자 기초 과정 / 투자 비중에 따른 손익 변화 / 내 주식은 왜 올랐을까/내렸을까?)와 우측 콘텐츠로 구성한다. 기본 진입은 이전 요청대로 투자 기초 과정이며, 좁은 화면에서는 세로 메뉴를 본문 위에 배치한다. 용어집 버튼과 과정 아래 보조 문장 퀴즈는 유지한다. 가격 변화 메뉴는 정보 확인 가이드와 D1·D2 수업 연결이며 개인 보유 종목 자동 분석은 미구현이다.

최신 통합 설계는 [14번 설계](14_학습콘텐츠_및_기능설계.md)를 따른다. 이전 아이디어 목록은 아래로 대체한다.

1. 현재: 투자 기초 과정을 학습 첫 화면에 배치, 학습 좌측 메뉴에서 비중별 손익 비교, 매수 시 가상 판단 자료와 현재 종목 메모를 연결.
2. 다음: 단계별 개념 학습 및 퀴즈. 선행 진단 → 설명 → 비교 → 확인 → 새 사례 전이 → 보충 설명. 영역별 수행 목표와 문항 검토가 선행 조건.
3. 데이터 계약 확보 후: 내 자산의 손실/이익 사건에서 관련 개념 학습. 평가/실현 구분·회복률·부분 매도·비중 기여만 근거가 있는 경우 제공. 사건 식별·동일 시각 데이터·원가 배분·중복 노출 제어가 선행 조건.
4. 제외: 용어 암기·거래 횟수 보상·손익 기반 성향 단정·학습 목표가 없는 활동.

기능별 맥락, 선정 규칙, 확인 문항, 도입 제외 조건은 14번 문서 2~7절에 명시한다.
