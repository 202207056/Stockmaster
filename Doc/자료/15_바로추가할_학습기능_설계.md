# 상황에 맞춰 바로 사용하는 학습 콘텐츠·상호작용

개정: 2026-09-15 · 최신 기준은 14번 재설계와 동일 · 구현 전 제안

## 역할

이 문서는 **학습 홈·뉴스·거래 화면에서 바로 사용할 수 있는 작은 실습과 상호작용**을 구체화한다. 코스는 이 활동에 설명을 더하는 선택형 콘텐츠이며 선행 이수를 요구하지 않는다. 용어집은 필요한 문맥에서만 참고한다. 각 기능은 실제 API 없이 가상 자료로 먼저 제작할 수 있으며, 실제 거래 연결에는 별도의 계좌·체결 계약이 필요하다.

## 1. 문장 속 개념 찾기 — 바로 시작하는 30~60초 퀴즈

- 넣을 곳: 학습 홈의 “이런 방식으로 이해를 돕습니다”, 뉴스·계좌 화면의 관련 활동. B1·D1 수업에서도 같은 콘텐츠를 사용한다.
- 예: “아직 팔지 않은 주식의 가치가 매입 때보다 2만원 줄었다.” → 현재 보유분의 평가 변화 / 매도해 확정한 결과 / 배당 지급 중 선택.
- 다른 예: “매출 20% 증가”가 “주가 상승 확정”을 뜻하는가? → 확정할 수 없으며 가격 판단에는 다른 정보도 필요.
- 정답 뒤 문장의 어떤 부분이 근거인지 강조한다. 용어 명칭만 맞히는 반복 문제로 확장하지 않는다.
- 초기 분량: 손익·주문·뉴스 각 2문항, 총 6개. 첫 확장 12문항의 일부로 편입하며 별도 6문항을 추가해 범위를 늘리지 않는다.
- 데이터: id, optional_lesson_id, sentence, options, correct_id, feedback_by_option, assumptions, version. 코스 연결 없이 독립 실행 가능.
- 완료: 모든 선택지 해설, 최초와 재시도 구분, 미응답은 미완료, 키보드 선택 가능.

## 2. 기사에서 근거 고르기 — D1 수업의 주요 실습

- 가상 기사 3~5문장을 제공하고 각 문장을 사실 / 해석 / 미래 추측으로 분류한다.
- 예: “매출 20% 증가”는 제시 자료의 사실, “비용 증가가 이익 감소의 원인일 수 있다”는 근거 확인이 필요한 해석, “다음 주 반드시 상승”은 미래 추측.
- 사용자가 확인한 사실 1개와 추가 확인할 점 1개를 판단 메모 초안으로 가져온다. 저장 전 사용자가 확인한다.
- 초기에는 교육용 가상 기사 사용. 기존 뉴스 목록과 연결할 때 원문 링크·발행 시각·열람 시각을 구분하고 검수되지 않은 실제 기사의 분류를 정답으로 자동 확정하지 않는다.
- 완료: 사실의 출처·가상 여부가 보이고, 근거 선택 결과가 초안에 연결되며, 자동 주문이 발생하지 않음.

## 3. 보유 비중 비교하기·주문 금액 미리보기

- 학습 홈에서 총자산 100만원인 가상 계좌 두 개의 주식 비중을 각각 조절하고 같은 등락률에 따른 손익을 나란히 비교한다. 초기값 A 80%·B 20%·등락 −10% → A −80,000원·B −20,000원. 코스 진입 없이 조작할 수 있다.
- 주문 화면에서는 수량 입력 시 예상 거래금액, 남은 현금, 해당 종목 비중이 함께 바뀐다.
- 교육 예: 현금 100만원, 해당 종목 0주, 가격 1만원 → 30주 입력 시 예상 거래금액 30만원·현금 70만원·비중 30%.
- 수업에서는 [주가 −10%] [주가 +10%]로 이후 계좌 변화도 비교한다.
- 실제 주문 화면은 선택 계좌와 기준 시각·비용 조건을 표시한다. 예상과 확정값을 구분하고 지연·실패 시 계산 불가 표시.
- 완료: 비중 0/100%, 잔고 부족, 수량 변경, 계좌 변경, 시세 실패 처리. 실제 적정 비중이나 매수 수량을 정답으로 제안하지 않음.

## 4. 계획 점검 질문 — E1·E2와 보유 종목 상세

- 매수 전: 확인한 사실 / 불확실한 점 / 다시 확인할 조건을 짧게 적는다.
- 보유 중: 원문을 펼쳐 보고 [유지] [수정] [보류]와 이유 선택. 계획을 지킨 횟수로 점수화하지 않는다.
- 매도 전: 과거 계획과 현재 매도 이유를 나란히 보여 준다. 입력은 선택이며 건너뛰기 가능.
- 자유 문장 조건은 사용자 점검만 지원한다. 재검토일은 화면 내 안내로 시작하고 푸시·실시간 자연어 조건 판정은 초기 범위에 넣지 않는다.
- 완료: 원본 보존, 수정 시각·이유 저장, 저장 실패가 주문 실패로 오인되지 않음. 메모만 재시도.

## 5. 부분 매도 비교 — B1·C2 및 매도 패널

- 현재 보유 30주에서 0주·10주·30주 매도 후 현금·잔여 수량을 나란히 본다.
- 10,000원에 산 30주를 현재가 9,000원에 10주 매도하면 실현손익 −10,000원, 남은 평가손익 −20,000원. 비용 제외.
- 선택한 매도 수량을 다르게 하더라도 우열을 매기지 않고 이후 가격 변화에 노출된 수량이 달라짐을 설명한다.
- 완료: 0주는 교육용 “매도하지 않음”이며 실제 주문 전송 불가. 전량 매도 후 원가·체결 이력은 삭제되지 않고, 일부 매도 결과가 전체 포지션 손익으로 표시되지 않음.

## 6. 거래 타임라인과 다음 질문 — E3 및 주문 내역

- 매수 근거 → 실제 체결 → 보유 중 점검 → 매도 이유 → 손익을 시간순으로 표시한다.
- 당시 정보와 나중에 들어온 자료를 구분한다. 없는 과거 근거는 자동 생성하지 않는다.
- “다음에는 무엇을 추가 확인할까요?”에 한 문장 답하고 관련 수업 하나로 이동한다.
- 초기에는 단일 매수·부분 매도 가상 데이터로 만든다. 실제 추가 매수·다회 매도는 서버 원가 배분과 계획-주문 다대일 연결을 합의한 뒤 제공한다.
- 완료: 시각 순서·연결 주문·계좌 일치, 근거 없는 인과 진단 없음, 확정 손익과 남은 손익 구분, 중복 사건 없음.

## 제작 묶음

1. 보유 비중 비교·문장 퀴즈 + 가상 계좌·판단 메모·부분 매도 복기를 코스 없이 사용할 수 있게 완성한다. A1·D1·E1은 관련 설명이 필요할 때 선택해 여는 콘텐츠로 제공한다.
2. A2·B1·C1을 더해 6개 코스 수업과 작은 확인 문제 12개로 확장한다.
3. 매수·매도 입력 옆 선택형 패널, 보유 점검, 주문 내역 복기로 실제 모의투자에 연결한다.
4. 나머지 9개 수업과 기존 AI 코칭 확장. 공수는 콘텐츠 검수와 API 준비 상태에 따라 별도 산정한다.

공통 컴포넌트 초안: LessonPlayer, ScenarioAccount, ContextQuestion, EvidencePicker, DecisionPanel, PlanCheckIn, TradeTimeline. 질문·시나리오·기록은 버전 관리하고, 브라우저 저장은 계정별로 분리하며 저장 불가 시 이번 방문만 유지된다고 안내한다. 앱 코드 수정은 이 문서 작업에 포함하지 않는다.
