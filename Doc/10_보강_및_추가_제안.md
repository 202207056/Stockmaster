## C. 프로젝트 완성도를 끌어올리는 추가 제안

### C-1. "초보자 친화"를 증명하는 장치 ★ 강력 추천
"UI를 간략화했다"는 주장은 근거가 필요합니다. 아래 중 2개만 해도 설득력이 확 올라갑니다.

1. **초보/전문가 모드 토글**
   - 초보: 시장가/지정가 2개만, 큰 버튼, 도움말 아이콘 항상 표시
   - 전문가: 호가창 10단, 분봉, 상세 지표
   - → "복잡한 HTS를 어떻게 간략화했는가"에 대한 **직접적 답변**
2. **주문 확인 모달의 평이한 언어화**
   ```
   삼성전자 10주를 327,000원에 사려고 해요.
   총 3,270,490원이 필요해요 (수수료 490원 포함 ⓘ).
   주문 후 남는 돈: 6,729,510원
   ```
3. **첫 사용자 온보딩 3분 코스** — 가입 → 설문 → 용어 5개 → 첫 주문 가이드 → 배지
4. **사용성 테스트 결과 첨부** — 주식 안 해본 친구 5명에게 "삼성전자 10주 사보세요" 시켜보고
   **소요 시간·막힌 지점 기록**. 개선 전/후 비교표는 보고서에서 매우 강력한 자료입니다.
   > 지금 `demo.html`이 이미 동작하므로 **이 테스트를 오늘도 할 수 있습니다.**

### C-2. 학습 효과 측정 지표 ★ 추천
"학습 플랫폼"을 표방했으므로 **효과를 데이터로 보여주면** 발표의 격이 달라집니다.

| 지표 | 산출 |
|---|---|
| 학습 전/후 승률 변화 | 개념 완료 전후 30일 승률 비교 |
| 학습 전/후 회전율 변화 | 뇌동매매 감소 여부 |
| 트리거 완료율 | `learning_trigger.is_completed` 비율 |
| 손절 규율 개선 | `stop_loss` 학습 후 손절 실행률 |
| 용어 도움말 클릭 TOP 10 | 초보자가 가장 어려워하는 용어 = 연구 결과 |

> 팀원 6명이 2주간 직접 써서 데이터를 쌓으면 **소규모지만 실제 데이터**로 발표할 수 있습니다.
> `trades` 테이블이 생기는 시점부터 데이터가 쌓이므로 **10월 초에는 시작**해야 합니다.

### C-3. 매매일지 (저비용 고효과) ★ 추천
주문 시 **"왜 샀나요?"** 를 한 줄 선택/입력받고, 매도 시 그 이유를 다시 보여줍니다.
```
매수 이유: "실적 좋아 보여서"  (2026-09-03)
지금 -12% 손실 중이에요. 그때의 판단은 어땠나요?
```
- 구현: `orders`에 `memo`, `reason_tag` 컬럼 2개 추가 (반나절)
- 효과: 뇌동매매 자각 → "비이성적 투자행태 개선" 기대효과에 직접 대응
- **투자 대비 효과가 가장 좋은 기능 중 하나**

### C-4. 시즌 & 랭킹 시스템 (COULD)
- 시즌(1개월) 단위 계좌 리셋, 시즌 종료 시 수익률 랭킹
- **단순 수익률 1위가 아니라 "리스크 조정 수익률" 랭킹**을 병행
  (샤프비율 유사 지표 = 수익률 / 변동성)
- → "고위험 몰빵이 아니라 건전한 투자를 장려한다"는 교육적 메시지와 일치
> 랭킹 API는 이미 있으므로(계산식만 고치면 됨), 추가 비용이 낮습니다.

### C-5. 데모 계정 & 시드 데이터 ★ 필수
심사 당일 새 계정으로 시작하면 **보여줄 데이터가 없습니다.**
```text
demo_beginner : 갓 가입 — 온보딩 화면 시연용
demo_active   : 30일 거래이력 — 수익률 그래프·포트폴리오 도넛 시연용
demo_loss     : 손실 트리거 3건 발동 — 학습 추천 카드 시연용
demo_coach    : AI 코치 리포트 생성 완료 — 성향-행동 불일치 시연용
```
→ `backend/scripts/seed_demo.py`로 자동 생성. **11월 첫 주에 반드시 준비.**

### C-6. Render 콜드스타트 대응 ★ 시연 필수
실측 결과 첫 요청이 **15초 이상 타임아웃 후 기동**했습니다. 시연 중 이러면 치명적입니다.

| 대응 | 방법 |
|---|---|
| 시연 직전 워밍업 | 발표 5분 전 `/` 를 한 번 호출해 깨워둠 |
| 상시 핑 | 외부 모니터링 서비스로 10분마다 `/` 호출 (무료 티어 유지 목적) |
| 로컬 백업 | 노트북에 로컬 서버 + 로컬 DB를 띄워두고 프론트 주소만 전환 가능하게 |
| 유료 전환 | 발표 기간만 최소 유료 플랜 |

> **로컬 백업이 가장 확실합니다.** `.env` 하나만 바꿔 전환되도록 준비하세요.

### C-7. 접근성 & 기본 품질 (저비용)
